複製するのは分割の形と比率。ウィンドウ登録を複製せず、元のタブと独立した ID を発行する。既存の保存形式・自由配置・旧カラム配置を維持する。

## 調査と復元処理

ログ上では同じテキストエディットの登録が、終了時に `invalidUIElement` となり、再起動の列挙で再紐付けされていた。どの OS イベントで参照が失効したかはログから断定できない。従来の終了経路には参照を取り直す処理がなく、登録時の参照だけで復元していた。

終了時は復元対象の各窓について AX の一覧を読み、同一 pid と CGWindowID の要素へ更新してからフルスクリーン判定と復元を行う。タイトルによる推定では別窓を操作しない。最小化・フルスクリーンを除外する通常の登録候補一覧も使用しない。

AX の一覧に見つからない場合は WindowServer の全窓一覧でも確認する。両方で存在しないと確認できた場合だけ実行時の紐付けを外し、登録情報は次回起動の再同定用に保持する。タイムアウトや不完全な情報は消滅と扱わず、既存参照による復元を試す。復元自体が失敗すれば従来どおり失敗を記録し、成功と断定しない。

pid ごとの処理と pid 間の並列性、3 秒の終了期限、画面切断・フルスクリーンの保護は維持する。一括の参照更新を全アプリで待ってから復元する構成にはしていない。通常運転中の解除処理は変更しない。

参照更新によって復元可能になるケースと、消滅した窓へ書き込まないケースは、修正前のエンジンでテストが失敗することを確認してから修正した。

## 複製操作

タイルタブの右クリックに日英の「タイル構成を複製」を追加。適用済み構成を同じ画面の元タブの直後へ作り、名前の重複時には連番を付ける。すべての分割・タイルに新しい UUID を割り当て、空の登録リストで開始する。アクティブタブは切り替えず、実窓への操作もしない。

## 確認手順

1. タイルを左右・上下に分割し、比率を調整して「適用」。タブの右クリックで「タイル構成を複製」を選ぶ。
2. コピーが元タブの直後に現れ、登録数が 0、形と比率が同じことを確認する。
3. コピー側を編集し、元タブの構成・登録窓が変わらないことを確認する。再起動後も両方の構成が残ることを確認する。
4. 非アクティブタブに登録窓を置き、TabDesk を通常終了する。画面外へ退避していた窓が表示領域へ戻ることを確認する。
