## 修正した不具合

1. **タイルモード復帰時の割り当てずれ** — 自由配置中に追加した窓を既存窓より前に並べると、既存窓のタイルを先に取得していた。既存の有効な割り当てをすべて予約してから、新規・未割り当ての窓を配置する。空タイルの有無、再実行の冪等性、JSON 読み込みをテストした。
2. **古い編集による割り当ての上書き** — 編集開始後に窓の割り当てだけが変わっても、分割の木が同じなら適用を受け付けていた。分割と割り当ての両方を、直列化された確定処理内で開始時の値と比較する。競合時は現在状態と下書きを保持し、既存の日英メッセージで読み直しを案内する。未復元窓でも同様に保護する。
3. **エラー表示が通常の状態通知で消える** — 未適用の編集がない状態でエラーが発生すると、その後の状態更新で消されていた。自動同期と利用者による「読み直す」を分け、エラーは通常更新・言語切替では保持する。
4. **サイドバーの配置警告が更新されない** — 描画省略の判定が永続ワークスペースだけを見ていたが、操作失敗は実行時の状態で管理される。警告の再評価を行の描画省略より前に移し、行の再生成を避ける既存の動作は維持する。
5. **自動復帰成功後も配置失敗の警告が残る** — スナップバックが成功した際、失敗フラグを解除していなかった。成功時に解除し、ワークスペースが同じでも画面へ通知する。実窓の代わりに偽ドライバを使い、書き込み失敗からの復帰と通知をテストした。

1・2・3・5 は修正前にテストが失敗することを確認。4 は描画の早期 return と、状態値を変えずに警告が変わる通知経路を照合して修正した。

## 利用者向け確認手順

1. タイルへ窓を登録し、自由配置へ変更する。窓を追加して一覧の先頭へ移動し、タイルへ戻す。元の窓が同じタイルに残ることを確認する。
2. タイルが 1 個の状態で編集画面の「結合」を押す。エラーが出た後、言語を切り替えても内容が残り、「読み直す」で消えることを確認する。
3. タイルが小さすぎる窓を登録し、警告を確認する。タイルを広げて適用し、実際に収まった場合に警告が消えることを確認する。

編集の同時更新と AX の一時的な失敗は通常操作で再現しにくいため、該当する自動テストで検証する。テストは一時ディレクトリと偽ドライバを使い、利用者の登録窓・保存設定を変更しない。
