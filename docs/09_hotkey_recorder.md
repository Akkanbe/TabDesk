既存の hotkeys.json の文字列表現は維持する。キーコードと修飾キーから同じ表現を作り、画面には ⌃⌥⇧⌘ の記号で表示する。

## 操作

1. 「ホットキー設定を開く」を選ぶ。
2. 設定欄をクリックして Control / Option / Shift / Command とキーを押す。
3. 記録した組み合わせを確認し、「保存して適用」を押す。

Esc単独は記録のキャンセル、Delete単独は解除。修飾キー付きのTab・Return・Esc・Deleteは割り当てに使える。
Tab単独は記録をキャンセルして次のコントロールへ移動する。「×」での解除も保存までファイルへ反映しない。

## 保守時の注意

- 記録に使うローカルイベント監視は設定ウィンドウのキー入力だけを消費し、終了・キャンセル・フォーカス移動時に削除する。
- Carbon登録を一時解除しないと、既存のCtrl+Tab等がローカルイベント監視へ届かない。
- 復帰時は記録前に適用していた割り当てを使い、未保存のフォーム値を登録しない。
- 登録解除が失敗した参照は保持して再試行する。残存参照がある間は新規登録をせず、重複登録を防ぐ。
- アプリ終了後の復帰では登録を再開しない。
- 文字列パーサと記録処理でキー表を共用する。文字変換中の入力文字列に依存せず、物理キーコードを保存する。キー名は従来のANSI表記に対応する。
- macOSや他アプリが予約するキーは届かない場合があり、その場合は別の組み合わせを選ぶ。
