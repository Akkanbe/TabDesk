# TabDesk 利用ガイド

TabDeskは、他のMacアプリのウィンドウをディスプレイごとのタブにまとめる、メニューバー常駐アプリです。
タブを切り替えると、そのタブの窓が表示され、他のタブの窓は画面外へ退避します。書類を閉じる操作ではありません。

現在は配布準備中です。`unnotarized` と付くZIPは未公証の検証用で、一般公開用の完成版ではありません。
初回の配布対象はApple Silicon（Mシリーズ）のMacを予定しています。アプリの起動条件はmacOS 15以降ですが、正式な対応範囲は各OSでの検証完了後に確定します。

## インストールと最初の起動

1. 配布元・バージョン・対応環境を確認し、ZIPを展開します。
2. 旧版が動いている場合は、下記の「更新」を先に行います。
3. `TabDesk.app` をApplications（アプリケーション）フォルダへ移して開きます。複数のコピーを同時に起動しないでください。
4. メニューバーのTabDeskアイコンと、各ディスプレイ左端のサイドバーを確認します。Dockには表示されません。
5. システム設定の「プライバシーとセキュリティ」→「アクセシビリティ」でTabDeskを許可します。見つからなければ「＋」から配置したアプリを追加します。

アクセシビリティ権限は、登録した他アプリの窓の位置・サイズ・フォーカスを操作するために必要です。
拒否した場合は、メニューの「アクセシビリティ設定を開く」から後で変更できます。

未公証版ではmacOSに起動をブロックされる場合があります。起動できなければ開発者へ確認してください。
公証済みの版でも初回のダウンロード確認は表示されます。macOSの案内は [Appleのサポート](https://support.apple.com/ja-jp/102445) を参照してください。

## 最初に試す操作

1. 保存済みのテスト用書類を開きます。最初はその窓1つで試します。
2. サイドバーの「＋」でタブを作ります。「＋ ウィンドウを追加」から窓を登録します。登録時に窓の位置・サイズが変わります。
3. もう1つタブを作り、クリックで切り替えます。元のタブに戻すと登録窓が表示されます。
4. 複数画面なら `Control + Option + →` で次の画面へ移り、続けて `Control + Option + 1` でその画面の先頭タブを選びます。

新しいタブはタイル配置です。タブを右クリックして「タイルを編集…」で分割を設定するか、レイアウトを自由配置へ変えられます。
自由配置の窓を動かして位置を記憶させたい場合は、編集モードを有効にします。編集モードが無効だと窓は登録位置へ戻ります。

| 操作 | 既定のホットキー |
| --- | --- |
| 次／前のディスプレイを選ぶ | Control + Option + → / ← |
| 選択中の画面の次／前のタブ | Control + Tab / Control + Shift + Tab |
| 選択中の画面の1〜9番目のタブ | Control + Option + 1〜9 |
| フォーカス中の窓を、その画面のタブへ登録 | Control + Option + R |
| 編集モード切替 | Control + Option + E |
| 選択中の画面のサイドバー折りたたみ | Control + Option + S |

これらは他のアプリの使用中にも働くホットキーです。特にControl + Tabはブラウザ等の操作と競合します。
メニューの「ホットキー設定を開く」で変更・解除し、「保存して適用」を押してください。

画面切替キーはマウスポインタを動かしません。選択した画面のサイドバーに枠が付き、空タブなど入力先の窓がない場合はオレンジ色になります。
その場合も続けてタブ変更ができます。別画面の窓をクリックした場合は操作対象も追従します。

## 任意の権限と設定

- 「タブサムネイルを表示」は既定で無効です。有効にすると窓の画像を取得するために画面収録の権限が必要です。許可後に再起動が必要な場合があります。サムネイルを使わなければ、この権限は不要です。
- 「ログイン時に起動」は必要な場合だけ有効にしてください。
- 「表示言語 / Language」で日本語とEnglishを選べます。
- 「URL コマンドを許可(自動化用)」は既定で無効です。通常の操作では有効にする必要はありません。

## 保存されるデータ

Finderの「移動」→「フォルダへ移動…」に以下のフォルダを入力すると開けます。

| 場所 | 内容 |
| --- | --- |
| `~/Library/Application Support/TabDesk/` | `state.json` にタブ・登録窓・配置、`hotkeys.json` にホットキー。移行・読み込み失敗時のバックアップもこのフォルダに残ります |
| `~/Library/Logs/TabDesk/` | `tabdesk.log` とローテーションしたログ |
| macOSのTabDesk設定領域（ドメイン `io.github.akkanbe.tabdesk`） | 表示言語、サイドバーの幅・折りたたみ、各種表示設定など |

設定とログにはウィンドウのタイトルなどが含まれます。問題報告時は書類名・個人情報などを伏せて、必要な範囲だけ共有してください。
現在のサムネイルはアプリのメモリ上に保持され、サムネイル画像ファイルとして保存する実装はありません。

## 更新とバックアップ

1. 書類を保存し、Macのロックを解除します。切断した画面に登録窓があれば、その画面を再接続します。
2. TabDeskのメニューから通常終了します。退避していた窓が戻ったことを確認します。戻らない場合は、アプリを入れ替える前に「窓が見つからないとき」を行います。
3. Finderで `~/Library/Application Support/TabDesk/` フォルダ全体を、日付入りのバックアップフォルダへコピーします。自動生成のバックアップは更新直前の全設定を必ず保持するものではないため、手動コピーを残します。
4. 表示言語なども保存する場合は、下記のコマンドでmacOSの設定領域をエクスポートします。
5. 旧版の `TabDesk.app` をApplications以外のバックアップ場所へ移して保管し、新版をApplicationsへ配置します。
6. 新版を起動し、タブ・登録・ホットキーと、画面切替→タブ変更→入力を確認します。「ログイン時に起動」を使っている場合は、その状態も確認します。

表示設定のバックアップ（TabDeskを終了してからターミナルで実行）:

```bash
tabdesk_backup_dir="$(mktemp -d "$HOME/Desktop/TabDesk-preferences.XXXXXX")"
defaults export io.github.akkanbe.tabdesk "$tabdesk_backup_dir/preferences.plist"
```

初回起動前など、設定領域がまだなければエクスポートは失敗する場合があります。成功してファイルが作成されたことを確認してください。
アクセシビリティ・画面収録の許可やログイン項目は、このバックアップでは復元されません。

更新後にアクセシビリティがONなのに動作しない場合は、TabDeskを通常終了し、システム設定の一覧からTabDeskを「−」で外して、Applicationsの新版を「＋」で追加・許可して再起動します。
特に開発用署名から別の署名への移行やad-hoc署名での再ビルドでは、再許可が必要になることがあります。

自動更新はありません。更新のたびに上記の手順で入れ替えます。

## 窓が見つからないとき

メニューの「ウィンドウの復旧手順…」からも同じ案内を開けます。

1. Macのロックを解除し、TabDeskが終了していれば起動します。
2. サイドバーを展開し、対象の窓が登録されているタブを選びます。
3. 「未復元」の場合は相手アプリを開き、最小化・フルスクリーンを解除して、メニューの「未復元のウィンドウを再検索」を選びます。
4. 判別できなければ未復元の登録行をクリックし、正しい窓を手動で割り当てます。非選択タブの窓は、そのタブを選ぶと表示されます。
5. 切断したディスプレイのタブなら、そのディスプレイを再接続します。
6. 窓が戻ったことを確認して、必要なら登録行の「×」でTabDeskの管理から外します。書類そのものは閉じません。

強制終了やロック中の終了では、窓が画面外に残ることがあります。復旧する前に設定ファイルを削除しないでください。
改善しなければ発生時刻、macOSのバージョン、画面構成、再現手順、関連するログを開発者へ伝えてください。
アプリのバージョンはFinderで `TabDesk.app` を選び、「情報を見る」で確認できます。検証用ZIPのビルド番号は付属の `build-info.txt` にあります。

## バックアップへ戻す場合

まず窓の復旧を済ませてTabDeskを通常終了し、現在の設定も別途コピーして残してください。
保存形式が古いアプリと互換であるとは限りません。開発者へ版の組み合わせを確認したうえで、旧アプリと、その版で保存した `Application Support/TabDesk` フォルダをセットで戻します。
表示設定も戻す場合は、終了中に `defaults import io.github.akkanbe.tabdesk "/実際のバックアップ先/preferences.plist"` を使います。パスは実際の保存先へ置き換えてください。
起動後に権限・登録・表示設定を確認し、曖昧な窓は手動で割り当てます。

## アンインストール

1. Macのロックを解除し、登録先ディスプレイを接続します。
2. TabDeskの「ログイン時に起動」を無効にします。
3. メニューから通常終了し、退避していた窓が戻ったことを確認します。戻らない場合は先に復旧します。
4. Applicationsの `TabDesk.app` をゴミ箱へ移します。
5. 必要ならシステム設定でTabDeskのアクセシビリティ・画面収録の許可を外します。

再インストールに備え、設定とログはそのまま残せます。不要になった場合に限り、バックアップを取ってから上記のTabDesk専用フォルダをFinderでゴミ箱へ移してください。
表示設定はmacOSの設定領域に別途残ります。書類の削除や相手アプリのアンインストールは必要ありません。
