# タブごとのタイルモード

## 要件

- [x] 既存の列配置・サイドバー幅追従・保存形式を調査
- [x] 手動分割・結合と境界ドラッグを採用（利用者の回答で確定）
- [x] タイルとウィンドウ割り当ての保存形式、旧設定の移行を実装
- [x] タイル配置とサイドバー幅・折りたたみへの追従を実装
- [x] タブごとのモード選択、タイル編集・登録 UI を日英で実装
- [x] 配置制約・保存復元・画面変更の回帰テストと UI 検証
- [x] 本体・PoC のビルドと更新用アプリの準備

利用者の要件：タブごとにタイルモード／自由配置モードを選択でき、新規タブはタイルモードが既定。タイルは矩形で、サイドバーを除く領域全体を隙間なく覆い、互いに重ならない。ウィンドウをタイルへ登録すると、その位置とサイズに固定する。サイドバーの幅変更や折りたたみでは、タイルの横幅を追従させる。

## 調査結果

既存の `TabLayout.columns` は、紐付け済みウィンドウの数で領域を等幅の列に分割する。ウィンドウ消失・解除のたびに列を作り直すため、空タイルや個別の分割比率を保存できない。タイルとウィンドウを別に保持する必要がある。

サイドバー除外領域は既存の `ScreenLayout` / `DisplayLayout.contentArea` を再利用する。境界を領域内の比率で保存し、共有境界から矩形を算出すれば、サイドバー幅変更でもタイルの隙間・重複を防げる。

既存の配置処理にはアプリ側の最小サイズによって要求したサイズに到達しない場合がある。旧 columns モードは到達したサイズを採用し、重なりを許している（`docs/04_v2_design.md`）。新方式ではタイルの幾何学的な非重複と、実ウィンドウの配置成功を別に検証し、失敗を無言で成功扱いしない処理が必要。

既存の自由配置を更新時に突然並べ直すことは避け、新規タブの既定値だけをタイルモードへ変更する。現在の日本語・英語対応の変更は保持し、新 UI も両言語を用意する。

## 実装した操作

- 新規タブは全領域を占める 1 タイルで開始する。タブの右クリックで「レイアウト: タイル／自由配置」を選ぶ。既存の旧カラム配置は、そのまま保持し選択状態を表示する。
- 「タイルを編集…」で専用の編集画面を開く。クリックまたはプルダウンでタイルを選択し、左右／上下に分割する。境界ドラッグで比率を変更する。
- プレビューはサイドバーを除いた領域の縦横比を保つ。余白はプレビュー表示上の余白であり、実際のタイル間には隙間を作らない。
- 同じ二分割から生まれた隣接する葉タイルを結合する。両方が占有済みなら拒否する。分割された領域をまとめ直すときは、内側の分割から順番に結合する。
- 編集は「適用」まで実窓へ反映しない。「読み直す」で未適用の変更を破棄する。追加のウィンドウを登録する前に、タイル編集を適用する。
- 空タイルを選び「このタイルにウィンドウを追加…」で登録する。既存の「ウィンドウを追加」や登録ホットキーは最初の空タイルを使い、満杯なら理由を表示する。
- 登録済みウィンドウはプルダウンで割り当て先を変更する。占有済みタイルへの割り当ては窓同士を入れ替える。ウィンドウを解除しても空のタイルは残る。
- 自由配置へ切り替えたときは現在のウィンドウ位置・サイズを引き継ぐ。タイルの構成は保存しておき、タイルモードへ戻すと再利用する。

## 保存と配置の境界

`Tab.tiles` は二分割の木（分割軸・比率・子ノード）、`ManagedWindow.tileID` は葉タイルの UUID。空タイルと再起動後の未復元ウィンドウにも同じ ID を保持する。旧 JSON のキー欠落は読み込める。保存済みの自由配置は更新時に変更しない。

タイル形状は `DisplayLayout.contentArea` から計算し、共有境界を丸める。ウィンドウ操作は従来の直列化・フルスクリーン保護・切断ディスプレイ保護を通す。自由配置の窓を別画面へドラッグして新規タブが作られる場合は、その窓の自由配置を引き継ぐ。

編集の上限は 64 タイル、木の深さ 16、分割比率 5〜95%。画面上で幅または高さが 40pt 未満になる編集は拒否する。実アプリにはこれより大きい最小ウィンドウサイズがある場合がある。

**タイルの矩形は重ならないが、他アプリが要求した位置・サイズを拒否する場合まで強制はできない。** 到達できなかった窓がある場合はサイドバーと編集画面に警告する。タイルを広げて再適用するか、自由配置を選べる。到達した実サイズを記録し、不可能なサイズ変更を延々と繰り返さない。IPC 自体が失敗した場合も成功表示にせず、再適用が成功すると警告を解除する。

## 確認手順

1. 新しいタブを作成し、右クリックでタイルモードにチェックがあることを確認。
2. 「タイルを編集…」で左右分割し、片方を上下分割する。境界をドラッグしてから「適用」。
3. 空タイルごとにウィンドウを追加する。選んだ矩形へ位置とサイズが合うことを確認。
4. サイドバーの幅を変更し、折りたたみ・展開する。タイル全体が領域に追従することを確認。
5. 割り当てプルダウンで窓を入れ替える。窓を 1 つ解除し、その空タイルと隣を結合する。
6. 自由配置／タイルを切り替え、通常終了後に再起動して分割と割り当てが残ることを確認。
